# 🚀 Apex — Unoesc

### 💻 Projeto Acadêmico | Desenvolvimento Web

O **Apex** é um projeto acadêmico desenvolvido no contexto da Unoesc, com foco na aplicação prática de conhecimentos em desenvolvimento web.

O projeto apresenta uma estrutura de páginas HTML, recursos visuais e formulários, permitindo explorar conceitos de organização de interfaces e estruturação de aplicações web.

---

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript (conforme implementação)

---

## 📂 Estrutura do Projeto

```text
Apex-Unoesc/
│
├── assets/
├── forms/
├── index.html
├── blog.html
├── blog-single.html
├── portfolio-details.html
├── changelog.txt
└── README.md
```

---

## 📄 Páginas do Projeto

- **index.html:** Página inicial
- **blog.html:** Página de blog
- **blog-single.html:** Página de conteúdo individual
- **portfolio-details.html:** Página de detalhes do portfólio
- **forms/:** Arquivos relacionados a formulários
- **assets/:** Recursos visuais e arquivos auxiliares

---

## 🚀 Como Executar

1. Clone o repositório:

   git clone https://github.com/WillianF3/Apex-Unoesc.git

2. Acesse a pasta do projeto.

3. Abra o arquivo `index.html` no navegador.

---

## 🎯 Objetivo

Aplicar conhecimentos de desenvolvimento web, aprimorando habilidades em:

- Estruturação de páginas HTML
- Organização de arquivos
- Desenvolvimento de interfaces
- Versionamento de código com Git e GitHub
